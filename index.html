☁️ Free Cloud VM Deployment Guide (No Credit Card)

Deploy this university project online for free without requiring a credit card using any of the following 3 options:

Option 1: Render.com Free Web Service Zero Credit Card

1. Push this folder to a GitHub repository.
2. Sign up on Render.com with GitHub (no card needed).
3. Click New + → Web Service → Select your repo → Build: npm install, Start: npm start. Done!

Option 2: Instant Public Cloud Tunnel (Cloudflare) 100% Free / Instant URL

Expose this server with a live, global HTTPS URL from your laptop or VM without port forwarding:

npm run tunnel

Generates a secure live URL like https://your-project.trycloudflare.com to share with your professor!

Option 3: AWS EC2 / Ubuntu Linux VM (1-Command Deploy)

If you have an AWS EC2 VM, AWS Academy Sandbox, or Linux server, run this script to install Node, PM2/Systemd, and Nginx automatically:

chmod +x setup-vm.sh && ./setup-vm.sh
